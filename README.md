# Selector de tanques WOT blitz

**Selector de tanques WOT blitz** es un proyecto programado en **Python** y **SQL**, cuyo objetivo es facilitar la elección de un tanque dentro del juego World Of Tanks Blitz por parte de los usuarios, ya sean jugadores que comienzan el juego o gente que anda aburrida. Los usuarios pueden elegir determinadas características de una lista extensa, y el programa se encargará de buscar los tanques que cumplan con ellas y luego mostrarlos. De la misma manera, los usuarios también pueden consultar la información relacionada a un tanque si lo desean.

## Prerrequisitos
poner python y mysql serverr

Esto es un proyecto que busca permitir a los usuarios seleccionar determinadas características, con el objetivo de encontrar un tanque de WOT blitz que cumpla con ellas.
